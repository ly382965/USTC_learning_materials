#### 2. 抖动（thrashing，有时被翻译为颠簸）产生的原因是什么？系统如何检测抖动？当检测到抖动时，系统应当如何处理？   

- 产生原因：抖动是由于物理内存资源不足与进程调度策略相互作用导致的恶性循环，当物理内存总量小于所有进程的工作集总和时，系统陷入 “缺页->置换->更多缺页” 的恶性循环，CPU利用率骤降
- 系统如何检测抖动：通过监控缺页率，CPU利用率与I/O等待时间等指标检测抖动
- 处理措施：挂起进程释放内存，切换局部置换算法，控制新进程调入等

#### 3. 伙伴系统中，伙伴的含义是什么？

伙伴指的是两个大小相同（通常为$2^k$）、物理地址连续、且可以合并成一个更大块（大小为$2^{k+1}$）的空闲内存块。

#### 4. 考虑某文件系统。采用组合索引方式，其中包含12个直接索引，其它均为一个。磁盘块的大小为8KB，数据块索引指针需要4字节来存储。请问此文件系统中文件最大多大？

设有一级，二级，三级间接索引块

- 直接索引（12 个）
- 一个一级间接索引块可存储 8kB/4B=2048个指针，数据块数为2048
- 一个二级间接索引块指向8kB/4B=2048 个一级索引块，数据块数为$2048^2$
- 一个三级间接索引块指向8kB/4B=2048 个二级索引块，数据块数为$2048^3$

故最大为$(12+2048+2048^2+2048^3)*8\mathrm{KB}=64.03\mathrm{TB}$

**连续分配**：

a）文件占据一组连续的物理磁盘块。内存中存储文件的起始块号（`start_block`）和总块数（`length`）。
逻辑块号 `n` 映射到物理块号：

$\text{物理块号} = \text{start\_block} + n \quad (0 \leq n < \text{length})  $

b）连续分配起始块号和总块数已在内存中，逻辑块4的物理地址可直接计算得出。故只需要读取1块。

**链接分配**：

a）每个数据块末尾存储指向下一个块的指针，内存中存储文件的首块地址。访问逻辑块n时需要需遍历链表。

b）需要从首块地址遍历，即需要读取5块。

**索引分配**：

a）文件拥有一个已在内存的索引块，存储所有数据块的物理地址。

b）索引块已经在内存中，故可以直接读取地址。只需要读取1块。

#### 7. 在RAID系统中，如何实现磁盘的并行？  

- 数据分条：文件数据被分割成固定大小的条带单元，轮询分布到所有磁盘上。
- 独立磁盘访问：每个磁盘独立处理I/O请求，无需等待其他磁盘。
- 并行校验计算：数据条带与校验条带并行写入不同磁盘。使得故障磁盘数据能从多磁盘并行重建。
- 镜像并发：相同数据复制到多个磁盘备份数据

#### 8. 常见的I/O控制方式有哪几种？

- 程序直接控制：CPU 主动轮询 I/O设备状态寄存器，检测设备是否就绪
- 中断驱动控制：CPU启动I/O操作后继续执行其他任务，设备就绪后向CPU发送中断信号；CPU暂停当前任务，通过中断处理程序传输数据。
- 直接内存访问(DMA)：CPU初始化DMA控制器（设置内存地址、数据量等）后释放CPU；DMA控制器直接管理设备与内存的数据传输，完成后通知CPU。
- 通道控制：通道为专用I/O处理器，执行通道程序。CPU仅发送I/O指令，通道独立执行全部I/O操作，完成后中断CPU。
