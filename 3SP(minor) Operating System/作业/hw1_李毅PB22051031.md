#### 1. 操作系统的三个主要作用是什么？

（1）操作系统作为计算机系统资源的管理者，包括处理机管理，存储器管理，文件管理，外设管理等

（2）操作系统作为用户和计算机硬件系统之间的接口，包括命令接口，程序接口等

（3）操作系统实现了对计算机资源的扩充

#### 2. 调研BIOS，说明BIOS的主要功能。

BIOS,全称基本输入输出系统(Basic Input/Output System),是计算机主板上固件的一个组成部分，位于操作系统内核之前，它的主要作用是为计算机提供最基本的硬件设备驱动程序和系统设置，以便在开机时对硬件进行初始化和自检，BIOS的主要功能包括以下几个方面：

- 硬件初始化：BIOS在计算机启动时负责对硬件进行初始化，包括检查硬件是否正确连接、配置内存参数、检测显卡等外设等，只有硬件初始化成功，操作系统才能正常加载。
- 系统设置：BIOS提供了一组预设的系统设置选项，用户可以根据自己的需求进行调整，这些设置包括日期、时间、语言、硬盘参数等，BIOS还支持启动顺序设置，可以指定不同设备的启动优先级。
- 软件固化：BIOS可以将一些常用的软件程序固化到硬盘上，以提高系统的稳定性和安全性，固化后的软件在下次启动时无需再次加载，直接运行即可。
- 故障诊断：BIOS提供了一些故障诊断工具，如POST自检程序、硬件诊断程序等，可以帮助用户快速定位硬件故障。
- 扩展功能：部分现代BIOS支持通过扩展接口与其他硬件设备进行通信，如网络适配器、串口等，这使得用户可以通过BIOS对这些设备进行管理和配置。

#### 3. 调研ppt中的helloworld源代码编译成可执行文件后，对应的可执行程序的入口地址是什么？是否是main函数的入口地址？说明你做出上述判断的依据。

在 C语言中，helloworld 源代码编译成可执行文件后，其可执行程序的入口地址不是 main 函数的入口地址，而是由操作系统的运行时环境所定义的程序入口点。通常为\_start符号。

#### 4. 调研脱机I/O，包括产生的原因、定义、目的、方法。

（1）定义

脱机 I/O（Offline I/O）是一种 I/O 处理方式，指通过专门的外围处理设备（如通道处理器、I/O 处理机）来独立执行 I/O 任务，使得 CPU 不必直接控制 I/O 设备，而是把数据的输入和输出交给这些专用设备，从而提高系统的吞吐量。

（2）原因

在计算机发展早期，I/O 设备（如磁带机、打印机）速度远远低于 CPU 的处理速度，导致 CPU 在执行 I/O 操作时需要长时间等待，造成资源浪费。为了减少 CPU 的空闲时间，提高计算效率，脱机 I/O 技术应运而生。

（3）目的

- 减少 CPU 等待时间：避免 CPU 直接管理慢速 I/O 设备，提高 CPU 利用率。
- 提高 I/O 设备吞吐量：多个 I/O 设备可以并行工作，提高数据传输效率。
- 减少 CPU 负担：使用专门的 I/O 处理机负责数据传输，使 CPU 只需处理计算任务。
- 优化系统性能：通过批量数据传输等方式，提高数据处理的连续性和效率。

（4）方法

- 脱机输入，先用外围设备（如磁带机、磁鼓）批量读取数据存入存储设备，然后再由 CPU 处理。例如：打孔卡片数据先存入磁带，然后 CPU 读取磁带数据处理。
- 脱机输出，先由 CPU 计算并将结果写入磁带或磁鼓，然后由专用设备（如行式打印机）从磁带读取并输出。例如：程序计算结果先存入磁带，随后由打印机打印。
- 使用通道处理器，在较高级计算机系统中，使用 I/O 通道（I/O Channel）或 I/O 处理机来管理 I/O 操作，支持并行处理。例如：IBM 大型机系统中的 I/O 通道可独立处理数据传输。

#### 5. 名词解释：2阶段调度（2-phrase of scheduling）（哪2阶段？）

为了提升调度效率并支持多种类型的任务，把资源和任务分开调度，第一层调度器负责管理资源并向框架分配资源，第二层调度器接收分布式集群管理系统中第一层调度器分配的资源，然后根据任务和接收到的资源进行匹配。这种调度架构就是两层调度。两层调度器中的第一层调度器仍是一个经简化的中央调度器，通常放在分布式集群管理系统中，而第二层调度则是由各个应用程序框架完成。

#### 6. 三种最基本的操作系统类型是什么？我们平常所使用的操作系统是什么类型的？

批处理操作系统、分时操作系统和实时操作系统。平常使用的操作系统均为分时操作系统
